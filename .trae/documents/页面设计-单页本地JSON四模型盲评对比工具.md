# 页面设计规格：评测工作台（单页，桌面优先）

## 1) Layout
- 桌面端采用「三段式纵向布局」：顶部固定工具栏 + 中部双栏内容区 + 底部状态/导出区。
- 中部内容区使用 CSS Grid：`grid-template-columns: 1fr 1.2fr`（左侧题目信息，右侧回答与评分）。
- 间距系统：8px 基础栅格（8/16/24/32）。容器最大宽度 1200–1400px，居中。
- 响应式：
  - >=1024px：双栏显示（左题目、右盲评区）。
  - <1024px：改为单栏堆叠（先题目，再回答）。

## 2) Meta Information
- Title：模型盲评对比工具
- Description：加载本地 JSON 题目列表，盲评展示四模型回答，按三维度 1–5 评分并导出 CSV/JSON。
- Open Graph：
  - og:title 同 Title
  - og:description 同 Description
  - og:type = website

## 3) Global Styles（设计令牌）
- 背景色：`#0B1220`（深色）或 `#F7F8FA`（浅色，默认建议浅色）
- 文字色：主文本 `#111827`，次文本 `#6B7280`
- 主色：`#2563EB`（按钮/高亮）
- 辅助色：成功 `#16A34A`、警告 `#F59E0B`、错误 `#DC2626`
- 字体：系统字体栈；字号层级：12/14/16/20/24
- 卡片：圆角 10–12px，轻阴影；Hover：阴影提升 + 边框高亮
- 按钮：
  - Primary：主色填充，hover 加深；disabled 降低不透明度
  - Secondary：描边按钮（灰/主色描边）
- 链接：主色下划线 hover

## 4) Page Structure（信息架构）
1. 顶部工具栏（固定）
2. 主内容区（Grid 双栏）
   - 左：题目与导航
   - 右：盲评回答卡片列表 + 评分面板
3. 底部状态栏（可折叠）

## 5) Sections & Components

### 5.1 顶部工具栏（Header Toolbar）
- 左侧：应用名「模型盲评对比工具」+ 数据集名称（若有）
- 中部：
  - 按钮「加载本地 JSON」(file input)
  - 按钮「加载样例」
  - 校验状态提示（成功/失败，失败可展开错误详情）
- 右侧：
  - 开关「显示模型名（复核）」默认关闭
  - 按钮「清空本地进度」触发二次确认弹窗

### 5.2 左栏：题目与导航（Problem Panel）
- 模块：题号与进度
  - 显示：`第 N / Total 题`、已完成数、完成率进度条
  - 控件：上一题/下一题按钮；题号跳转输入框（回车跳转）
- 模块：题目信息卡
  - 标题：Problem
  - 内容：等宽或易读排版；长文本默认折叠（“展开/收起”）
- 模块：User Status 卡
  - 标题：User Status
  - 内容：原文展示；可复制按钮（便于外部记录）

### 5.3 右栏：盲评回答区（Blind Review Panel）
- 顶部条：
  - 标签提示：当前为盲评模式（A/B/C/D）
  - 按钮「重新随机顺序」（可选；若实现，需提示会影响可比性并保留历史映射）
- 回答卡片列表（4 张）：
  - Card Header：回答字母（A/B/C/D）；若开启复核则在角落显示原始模型键
  - Card Body：回答文本（支持代码块/列表样式）；长文本可折叠；提供“复制回答”
  - Card Footer：评分区（见 5.4）

### 5.4 评分区（三维度 1–5）
- 每个回答卡包含：
  - 三个维度行（Dim1/Dim2/Dim3，占位命名；实现时用你定义的维度名称）
  - 每行 5 个可点击评分按钮（1–5），选中态高亮
  - 备注输入（单行或小文本域）
- 交互与校验：
  - 未完成三维度评分时，该回答卡显示“未完成”标记
  - 题目级别：四个回答均完成三维度后，才将题目标记为“已完成”
- 快捷键（桌面优先）：
  - `Alt + A/B/C/D` 聚焦到对应回答
  - 数字键 `1–5` 赋值到当前聚焦维度（或最后操作维度）

### 5.5 底部状态栏（Footer / Export Bar）
- 左侧：自动保存状态（“已保存/未保存”）+ 最近保存时间
- 中部：未完成提醒（例如：本题还差 X 个维度未评分）
- 右侧：
  - 按钮「导出 JSON」
  - 按钮「导出 CSV」
  - 导出前弹出摘要：题目数、完成数、是否包含 blind_mapping

## 6) Animation / Transition Guidelines
- 卡片展开/收起使用 150–200ms 过渡（高度/透明度），避免影响阅读。
- 评分按钮选中态使用 120ms 颜色过渡。
